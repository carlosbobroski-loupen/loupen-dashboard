## Armadilhas registradas para quem continuar

**Dívida real na watermark.** `sync_state.last_run_at` guarda a hora da *execução*, não o
`max(SystemModstamp)` do lote. Registro alterado **durante** a execução cai numa janela
cega de segundos. Corrigir usando o maior SystemModstamp do lote.

**`Amount` não é MRR.** Linha real: `Amount=708,00` com `MRR__c=2367,05`. A migration 073
guarda os dois crus. Qual sustenta receita por RecordType **ainda não foi decidido** — e
não deve ser adivinhado.

**`Identificador_RD__c` só existe desde 06/2026.** Qualquer junção RD ↔ Salesforce por essa
chave é cega antes de junho. É propriedade da fonte, não bug a corrigir no código.

**Não encoste no app do time de serviços.** O "Executar como" é do app inteiro; o
permission set do dashboard faz todo objeto fora de Lead/Account/Opportunity desaparecer
(provado: `Case` retorna *sObject type not supported*). Trocá-lo quebraria o dashboard
deles.

**O token público do RD Station não é segredo.** `c5c0947…` é a API Key pública: só escreve
conversão, não lê nada, e é feita para ficar exposta em formulário de site. Rotacionar não
reduz risco. Isso foi diagnosticado errado na primeira passada e corrigido no ADR-022.
